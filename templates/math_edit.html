📐 Jak zapisovat matematiku – rychlá nápověda

Ty píšeš jednoduchý zápis. Student uvidí skutečnou matematickou konstrukci; speciální značky má pevně a doplňuje jen čísla, proměnné a běžné operátory.

x**3 → mocnina x³
x**(1/2) → √x
12/18 → zlomek
abs(x) → |x|
log(x) → log(x)
ln(x) → ln(x)
log(x,2) → logaritmus se základem 2
pi → π
sin(x) → sin(x)
cos(x) → cos(x)
tan(x) → tan(x)
diff(x**2,x) → derivace
diff(x**3,x,2) → 2. derivace
integrate(x**2,x) → integrál
+ - * / : < > = <= >= != → běžné operátory

Pokud aplikace zápisu nerozumí, lekci neuloží a vyzve tě k opravě.
