# Občanská nauka – Já a moje osobnost

Společná interaktivní aktivita pro 45minutovou hodinu na interaktivní tabuli.
Technicky je balíček veden pod předmětem `fyzika`, aby jej bylo možné nahrát do stejné části portálu UCEBNICE FINAL.

Obsah:
1. Každý jsme jiný
2. Co tvoří osobnost
3. Vlastnost × dovednost
4. Jaký je člověk v situaci
5. Co mám rád
6. Co umím
7. Co se chci naučit
8. Společná závěrečná výzva

Ovládání je přizpůsobeno dotyku: velká tlačítka, minimum textu, bez nutnosti psaní.
