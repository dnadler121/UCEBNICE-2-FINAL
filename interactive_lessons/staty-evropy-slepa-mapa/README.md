# Mapa Evropy – procvičování a průběžný test

- Procvičování: neomezené pokusy, bez penalizace.
- Test: chyba práci neukončuje a nesnižuje získané procento.
- Procenta = počet správně umístěných států / 47.
- Správně vložené státy v Testu se ukládají k přihlášenému studentovi a obnoví se po dalším přihlášení.
- „Začít znovu“ v Testu uložený průběh smaže a začne od 0 %.

Vyžaduje verzi UČEBNICE s podporou trvalého stavu importovaných aplikací.


## Opuštění stránky
Tento balíček má `focus_guard: false` a `allow_page_leave: true`. Student může mapu kdykoli opustit nebo přepnout do jiného okna; správně uložený postup testu zůstává zachován.
